## Что такое ключ для VPN

Ключ (или «ключ доступа», «конфиг») — это строка с адресом сервера и параметрами подключения. Вы вставляете её в приложение-клиент, и оно подключается.

| Как выглядит | Что это |
|---|---|
| `vless://…@адрес:443?security=reality…` | ключ VLESS (самый распространённый в 2026) |
| `hysteria2://…@адрес:443?…` | ключ Hysteria2 (быстрый, для Wi-Fi и игр) |
| `ss://…` | Shadowsocks (старый, часто блокируется) |
| `https://…/sub/…` | **подписка**: ссылка на список ключей, обновляется сама |
| `happ://crypt…` | зашифрованная подписка для Happ |

## Ключ или подписка — что лучше

| | Одиночный ключ | Подписка |
|---|---|---|
| Сколько серверов | один | несколько стран и протоколов |
| Если сервер заблокируют | ключ «умирает», нужен новый | сервис меняет сервер, вы жмёте «Обновить» |
| Выбор протокола | какой дали | Wi-Fi / Mobile / Игровой |
| Удобство | вставлять вручную | один раз, дальше само |

**Вывод:** в 2026 году берите подписку, а не отдельные ключи.

## Почему бесплатные ключи не работают

1. **Перегрузка.** Один ключ из публичного списка используют тысячи человек, и скорость падает до нуля.
2. **Блокировка.** Публичные списки ключей на GitHub читает не только вы. Такие серверы блокируют первыми.
3. **Старые протоколы.** В бесплатных списках в основном VLESS Reality по TCP и Shadowsocks, а их в 2026 году режет ТСПУ.
4. **Безопасность.** Владелец сервера видит, куда вы ходите. Иногда такие «бесплатные» серверы поднимают специально, чтобы собирать данные.

## Как вставить ключ в Happ

1. Скопируйте ключ или ссылку подписки целиком.
2. Откройте **Happ** → **«+»** → **«Вставить из буфера»**.
3. Сервер появится в списке → нажмите на него → подключитесь.

Или нажмите кнопку **«Открыть в Happ»** в боте или на сайте сервиса — подписка добавится сама. Подробнее: [гайд по Happ](https://github.com/Filizaker2/happ-vpn-guide).

## Ключ не работает: что делать

- **«Ошибка подключения» / timeout** — сервер заблокирован или ключ истёк. Нужен новый ключ или «Обновить подписку».
- **Подключено, но сайты не грузятся** — протокол режется ТСПУ. Нужен ключ с **XHTTP** или **Hysteria2**.
- **Работает на Wi-Fi, не работает на мобильном** — нужен ключ для мобильной сети (XHTTP).
- **Ключ не вставляется** — скопирован не целиком (часто обрезается хвост после `#`).
